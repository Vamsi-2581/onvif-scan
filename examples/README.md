# Example reports

`sample-report-simulated.json` / `sample-report-simulated.html` — generated
by running the real scanner against the three simulated devices in
`tests/sim_device.py` (strict / standard / legacy personas, fictional
brands) on a loopback network. They are **simulated** reports: they show
the exact report format and findings behaviour, but they are not evidence
from real cameras.

Real-camera reports (redacted per CONTRIBUTING) will be added here as
device reports come in.
